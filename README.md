# Cadastro-de-produtos
 - Criei este projeto para praticar tratamento de arquivos JSON e lógica.
 - Um gerenciador de produtos simples que oferece diversas opções para gerenciamento de produtos:
    - Adicionar Produto
    - Remover Produto
    - Editar Produto
        - Editar Nome
        - Editar Estoque
        - Editar Preço
    - Listar Todos
    - Listar por ID


# Pré-requisitos
- Antes de começar, certifique-se de que cumpre os seguintes requisitos:
	- Python >= 3.9 (3.11+ recomendado)
	- rich >= Vá para a area de Instalação

## Instalação

- Veja como instalar:

```bash
# Clonar o repositório
git clone https://github.com/0xAA55-P/cadastro-de-produtos

# Instalar dependências
pip install -r requisitos.txt

# Executar o aplicativo
python run.py
```
